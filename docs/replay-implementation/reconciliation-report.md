## Gate B notes

- Lineup evidence levels: `corroborated` = no fallback, no structural violation, every on-court actor inside the tracked five, final five equals the box `active` five. Five distinct players alone is only structural; stints without any recorded action are listed because they are not independently evidenced (the player may simply not have touched the ball).
- Classification defaults (tunable via `validateReplay` options): >2% of events without period/clock → unavailable; a stat family is disabled game-wide when ≥3 players and ≥20% of verified players mismatch (fewer → disabled for those players only); a tracked final five ≠ box `active` limits that team's lineup from its last substitution to the end.
- Missing End of Game, or no end marker for the last period, → unavailable (truncated play-by-play). Missing header linescores is deliberately only a `period_scores_missing` warning (status can stay ready; final score and end markers still checked). Final requires completed + state `post` + `STATUS_FINAL*`.
